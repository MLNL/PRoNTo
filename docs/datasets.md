# PRoNTo Datasets

This page lists benchmark datasets from different neuroimaging modalities that can be freely downloaded and analysed with PRoNTo. Step-by-step analyses of these datasets are described in the tutorial chapters of the [manual](manual.md).

---

## Available Datasets

### Dataset 1: Haxby Dataset
An fMRI block design dataset with Faces and Objects in Ventral Temporal Cortex.

- **Download (PRoNTo version):** [Haxby_dataset.zip](http://www.mlnl.cs.ucl.ac.uk/pronto/datasets/Haxby_dataset.zip)
- **Original data:** [http://www.pymvpa.org/datadb/haxby2001.html](http://www.pymvpa.org/datadb/haxby2001.html)

---

### Dataset 2: OASIS Dataset
Structural MRI data from the Open Access Series of Imaging Studies.

- **Download (PRoNTo version):** [OASIS.zip](http://www.mlnl.cs.ucl.ac.uk/pronto/datasets/OASIS.zip)
- **Original data:** [https://www.oasis-brains.org/](https://www.oasis-brains.org/)

---

### Dataset 3: IXI Dataset
Structural MRI data from the IXI (Information eXtraction from Images) project.

- **Download (PRoNTo version):** [IXIdata.zip](http://www.mlnl.cs.ucl.ac.uk/pronto/datasets/IXIdata.zip)
- **Original data:** [http://brain-development.org/ixi-dataset/](http://brain-development.org/ixi-dataset/)

---

### Dataset 4: Multimodal Face Recognition Dataset
Multimodal neuroimaging dataset for face recognition tasks.

- **Download (PRoNTo version):** [Multimodal_face_dataset.rar](http://www.mlnl.cs.ucl.ac.uk/pronto/datasets/Multimodal_face_dataset.rar)
- **Original data:** [OpenNeuro ds000117 v1.0.4](https://openneuro.org/datasets/ds000117/versions/1.0.4/)

---

### Dataset 5: Simulated ECoG Dataset
Simulated data based on an ECoG resting-state recording from a single patient.

- **Download (PRoNTo version):** [SimulatedECoG.rar](http://www.mlnl.cs.ucl.ac.uk/pronto/datasets/SimulatedECoG.rar)
- **Original data / more info:** [https://github.com/JessicaSchrouff/Simulated_ECoG/](https://github.com/JessicaSchrouff/Simulated_ECoG/)

---

## Notes

- All datasets are provided for tutorial and educational purposes only.
- Please refer to the original data sources for licensing and citation requirements specific to each dataset.
- Step-by-step instructions for each dataset are in the [PRoNTo manual](manual.md).
