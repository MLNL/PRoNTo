# PRoNTo Tutorials

The following practical demonstration videos from the 2021 PRoNTo Course show
how to use PRoNTo step by step.

---

## Video tutorials — 2021 PRoNTo Course

### [Practical Demo 1 — Haxby fMRI dataset](https://mediacentral.ucl.ac.uk/Player/ag72chGh)
Classifying fMRI data while the subject looks at faces vs houses using an SVM model.

### [Practical Demo 2 — OASIS sMRI dataset](https://mediacentral.ucl.ac.uk/Player/Ff9hhAa0)
Classifying demented vs non-demented subjects using a Multiple Kernel Learning (MKL) model.

### [Practical Demo 3 — IXI sMRI dataset](https://mediacentral.ucl.ac.uk/Player/c3B1a6Hc)
Predicting age from structural MRI using a Kernel Ridge Regression (KRR) model.

### [Practical Demo 4 — Multimodal Face Recognition dataset](https://mediacentral.ucl.ac.uk/Player/5Ih1gd88)
Classifying famous vs scrambled face images by combining different data types (EEG (MEEG), interpolated EEG as NIfTI, and connectivity EEG as .mat) using a Multiple Kernel Learning (MKL) model.

For the full course including lectures, see the
[2021 PRoNTo Course page](http://www.mlnl.cs.ucl.ac.uk/pronto/prtcourse_2021.html).
