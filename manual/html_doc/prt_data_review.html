CROSS-REFERENCE INFORMATION

This function calls:
  • prt_check_design Function to check the design and discard scans which are either overlapping between conditions or which do not respect a minimum time interval between conditions (due to the width of the HRF function).
  • prt_get_defaults Function to get/set the defaults values associated with an identifier.
This function is called by:
  • prt_ui_design PRT_UI_DESIGN M-file for prt_ui_design.fig
  • prt_ui_main PRT_UI_MAIN M-file for prt_ui_main.fig
