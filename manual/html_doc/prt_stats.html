prt_stats

PURPOSE

Function to compute predictions machine performance statistcs statistics

SYNOPSIS

function stats = prt_stats(model, t,flag)

DESCRIPTION 

 Function to compute predictions machine performance statistcs statistics

 Inputs:
 ----------------
 model.predictions: predictions derived from the predictive model
 model.type:        what type of prediction machine (e.g. 'classifier','regression')

 t: true targets
 flag:  'fold' for statistics in each fold
         'model' for statistics in each model
 
 Outputs:
-------------------
 Classification:
 stats.con_mat: Confusion matrix (nClasses x nClasses matrix, pred x true)
 stats.acc:     Accuracy (scalar)
 stats.b_acc:   Balanced accuracy (nClasses x 1 vector)
 stats.c_acc:   Accuracy by class (nClasses x 1 vector)
 stats.c_pv:    Predictive value for each class (nClasses x 1 vector)

 Regression:
 stats.mse:     Mean square error between test and prediction
 stats.corr:     Correlation between test and prediction

0106 % for a binomial distribution using Wilson's 'score interval'
0107 %
0108 % IN
0109 %   k: scalar, number of successes
0110 %   n: scalar, number of samples
0111 %
0112 % OUT
0113 %   lb: lower bound of confidence interval

0115 %
0116 % REFERENCES
0117 % Brown, Lawrence D., Cai, T. Tony, Dasgupta, Anirban, 1999.
0118 %  Interval estimation for a binomial proportion. Stat. Sci. 16, 101?133.
0119 % Edwin B. Wilson, Probable Inference, the Law of Succession, and
0120 %   Statistical Inference, Journal of the American Statistical Association,
0121 %   Vol. 22, No. 158 (Jun., 1927), pp. 209-212
0122 
0123 alpha=0.05;
0124 
0125 l=norminv(1-alpha/2,0,1);
0126 p=k/n;                    % sample proportion of success
0127 q=1-p;
0128 
0129 % compute terms of formula
0130 firstTerm=(k+(l^2)/2)/(n+l^2);
0131 secondTerm=((l*sqrt(n))/(n+l^2))*sqrt(p*q+((l^2)/(4*n)));

0133 % compute upper and lower bounds
